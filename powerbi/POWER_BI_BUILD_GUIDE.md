# Power BI Dashboard Build Guide

## Data source
Use `data/processed/clean_orders.csv` generated by `src/etl.py`.

## Model
Create a Date table and relate `Date[Date]` to `clean_orders[order_date]`. Keep the fact table at order-item grain and use `DISTINCTCOUNT(order_id)` for order KPIs.

## Core measures
```DAX
Total Orders = DISTINCTCOUNT(clean_orders[order_id])
Total Order Items = DISTINCTCOUNT(clean_orders[order_item_id])
Total Sales = SUM(clean_orders[sales])
Total Profit = SUM(clean_orders[profit])
Profit Margin % = DIVIDE([Total Profit], [Total Sales])
SLA Breach % = AVERAGE(clean_orders[sla_breach])
Avg Delivery Delay = AVERAGE(clean_orders[delivery_delay_days])
Avg Actual Shipping Days = AVERAGE(clean_orders[actual_shipping_days])
Avg Scheduled Shipping Days = AVERAGE(clean_orders[scheduled_shipping_days])
Average Order Value = DIVIDE([Total Sales], [Total Orders])
```
Format margin/breach as percentages.

## Page 1 — Executive Overview
- KPI cards: Total Orders, Sales, Profit, Profit Margin, SLA Breach %, Avg Delay
- Line chart: Sales and Profit by Month
- Bar chart: Profit by Market
- Slicers: Market, Region, Shipping Mode, Customer Segment

## Page 2 — Delivery Performance
- Column chart: SLA Breach % by Shipping Mode
- Bar chart: SLA Breach % by Region
- Matrix: Region × Shipping Mode with Orders, Avg Delay, SLA Breach %
- Scatter: Sales vs SLA Breach % by Region

## Page 3 — Profitability
- Bar chart: Profit by Category
- Treemap: Sales by Category
- Table: Category, Sales, Profit, Margin %, SLA Breach %
- Line chart: Monthly Profit Margin %

## Page 4 — Market & Category
- Market comparison table
- Category performance table
- Region map if a suitable geographic visual is available
- Drill-through from market to region/category

## Dashboard design rules
- Use consistent units: USD for financial values and days for delivery metrics.
- Never label order-item count as order count.
- Use tooltips to show both sales and profit when possible.
- Add a note that SLA breach is an observed outcome metric, not a prediction.
